## アプリ名
Weather-app

## 概要
PythonのGUIライブラリであるTkinterを使って作成した天気予報アプリです。  
学習目的で作成しており、Tkinterを使ったGUIレイアウトの基礎やPythonの基本文法、関数、制御構文などの理解を深めることを目的としています。

## 主な機能
・都市名を入力して天気を検索  
・APIを利用した天気情報の取得

## 使用技術
・Python 3.14  
・Tkinter  
・requests
・Open-Meteo API

## 使用API
・Open-Mteo API  
無料で利用でき、APIキーが不要な天気情報サービスです。  
公式サイト：https://open-meteo.com/

## 実行方法
1.リポジトリをクローンする  
GitHubからソースコードをダウンロードします。

git clone https://github.com/Kent-66/Python-Weather-app.git

2.プロジェクトのフォルダに移動する

cd Python-Weather-app

3.アプリを起動する  
Python3.14がインストールされていることを確認し、以下のコマンドを実行します。

Weather-app.py
